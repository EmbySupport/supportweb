    Backing up & Restoring Emby Server

    Application-data backups preserve server state, while media backups protect the source files in your collection.

    The guides will go over the following:

    • how to setup regular backups using the Backup & Restore Plugin. See Backing Up Emby Server.
    • how to migrate your settings from Emby Server from one machine to another. See Using Restore to add an Additional Server and Using Restore to migrate to a New System.
    • how to fully migrate to a new system. See Using Restore to migrate to a New System.
    • how to restore your server to the last backed up state. See Restoring Last Backup.
    • how to restore your server to a specific backup date of the databases. See Restoring an Earlier Backup of the Database.
    • how to copy playback state and favorites from one user account to another. See Using Restore to Copy Playback States and Favorites.

    All the above use the Emby Server Backup & Restore Plugin and will require Emby Premiere.

    An article is also provided for manual backups. See How to Backup Manually.
